# Dataset sources and usage conditions

The repository does not redistribute raw images or videos. Download each
dataset from its official source and review the current terms before use.

## CAUCAFall

- Role: source training/validation and held-out binary detector test.
- Official record: https://doi.org/10.17632/7w7fccy7ky.4
- Record page: https://data.mendeley.com/datasets/7w7fccy7ky/4
- Citation: J. C. Eraso Guerrero, E. Muñoz España, M. Muñoz Añasco, and
  J. E. Pinto Lopera, “Dataset for human fall recognition in an uncontrolled
  environment,” *Data in Brief*, 45, 108610, 2022.
- This release includes only a relative-path split manifest and derived
  temporal-state annotations; it includes no CAUCAFall media.

## UR Fall Detection (URFD)

- Role: external development and diagnostic evaluation.
- Official source: https://fenix.ur.edu.pl/~mkepski/ds/uf.html
- Stated terms: Creative Commons Attribution-NonCommercial-ShareAlike 4.0
  International, for non-commercial academic use.
- Citation: B. Kwolek and M. Kępski, “Human fall detection on embedded
  platform using depth maps and wireless accelerometer,” *Computer Methods
  and Programs in Biomedicine*, 117(3), 489–501, 2014.
- This release includes a manual event-boundary annotation table and compact
  result summaries, but no URFD media.

## Le2i Fall Detection Dataset

- Role: staged external evaluation and verifier-development evidence.
- Official record: https://doi.org/10.25666/DATAUBFC-2024-04-09
- Record page:
  https://search-data.ubfc.fr/imvia/FR-13002091000019-2024-04-09_Fall-Detection-Dataset.html
- Stated terms: CC BY-NC-SA on the official record; confirm the applicable
  license version and attribution wording at download time.
- This release includes compact result summaries only and no Le2i media.

## GMDCSA24 v2.1

- Role: one-time final blind test only.
- Archived dataset (v2.1): https://doi.org/10.5281/zenodo.13354453
- Source repository:
  https://github.com/ekramalam/GMDCSA24-A-Dataset-for-Human-Fall-Detection-in-Videos
- Zenodo terms: Creative Commons Attribution 4.0 International.
- Citation: E. Alam, A. Sufian, P. Dutta, M. Leo, and I. A. Hameed,
  “GMDCSA-24: A dataset for human fall detection in videos,” *Data in Brief*,
  57, 110892, 2024.
- This release includes an annotation-audit table, lock metadata, and compact
  blind-test summaries, but no GMDCSA24 media.

## Derived artifacts

Derived annotations and split metadata are supplied for scientific
reproducibility. Their use does not grant rights to the underlying media.
Users remain responsible for dataset attribution, non-commercial restrictions,
share-alike conditions, privacy requirements, and any additional terms imposed
by the original providers.
